# ECGR 2161 Final Project Site

A simple responsive static site template with a cover page and a separate project page.

- `index.html` — cover/home page
- `project.html` — project description, process, results, and team
- `styles.css` — shared styles

Replace the bracketed prompts and sample text with your project information. To publish with GitHub Pages, go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. GitHub Pages deployment may take a few minutes; check the **Actions** tab for a workflow named **pages-build-deployment**.
